**2026-05-19** — Conditions API resolved: SwellCloud (`api.swellcloud.net`). Coordinate-based, surf-focused, 4x daily model updates. Tide data not available in SwellCloud — deferred to V2 (NOAA CO-OPS flagged as candidate). Raw Data in V1 = swell height, period, wave direction, wind speed, wind direction. Tide removed from V1 scope.

**2026-05-19** — Break identity model resolved (revised): breaks are user-created objects — drop a pin, give it a label. All friends in your network instantly see it. No system-enforced deduplication in V1; if two friends create the same spot, one deletes the duplicate. Human convention handles it. Coordinates still anchor each break for conditions data fetching. Rationale: simpler to build, simpler to explain, no complex "join existing break" UX flow needed. V2 note: GPS deduplication radius of ~250m flagged as a candidate automation if manual dedup proves friction-heavy at scale.
