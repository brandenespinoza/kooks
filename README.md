# Kooks

A surf-crew presence PWA. Crew members check in at a Break with an ETA; the crew sees it in real time. Conditions verdicts are generated by an LLM from SwellCloud data on a schedule. Auth is invite-link only — no email, no password.

Built for a crew of about four people at one break. Architectural choices assume that scale: an in-process EventEmitter for SSE fan-out, pg-boss on the same Postgres, a single self-hosted instance behind Nginx Proxy Manager.

## Stack

Next.js 15 (App Router) · TypeScript strict · tRPC v11 · Prisma + PostgreSQL · Tailwind v4 · shadcn/ui · pg-boss · web-push

## Setup

```bash
npm install                 # runs `prisma generate` via postinstall
cp .env.example .env        # then fill in the values below
./start-database.sh         # local postgres container from DATABASE_URL
npm run db:migrate:dev      # create + apply migrations
npm run dev                 # next dev --turbo
```

### Environment

All variables are validated at startup by [`src/env.js`](src/env.js) (T3 env + Zod) — a missing one fails the boot with a clear message rather than at first use. Adding a variable means editing both the `server` and `runtimeEnv` blocks in that file **and** `.env.example`.

| Variable | Notes |
|---|---|
| `DATABASE_URL` | Postgres connection string |
| `SEED_INVITE_TOKEN` | Seeds the primary user; their invite link is `/join/[token]` |
| `SWELLCLOUD_API_KEY` | Marine conditions source |
| `OPENAI_API_KEY` | Conditions verdict generation — server-side only |
| `WEBCAM_URLS_JSON` | JSON map of Break label → webcam URL |
| `WEB_PUSH_PUBLIC_KEY` / `WEB_PUSH_PRIVATE_KEY` / `WEB_PUSH_EMAIL` | VAPID keys — `npx web-push generate-vapid-keys`; email must start with `mailto:` |
| `SESSION_SECRET` | 32+ chars — `openssl rand -base64 32` |

## Commands

```bash
npm run dev              # next dev --turbo
npm run typecheck        # tsc --noEmit
npm run build            # next build (validates env via next.config.js)
npm run db:migrate:dev   # prisma migrate dev
npm run db:generate      # prisma generate
npm run db:studio        # prisma studio
docker compose up --build   # full app + db stack, mirrors production
```

There is no ESLint, Prettier, or test runner configured. Verification for a change is `npm run typecheck` plus `npm run build` — use `SKIP_ENV_VALIDATION=1` when env vars are unavailable.

## Deployment

Push to `main` → GitHub Actions builds the image → GHCR → SSH to the VPS → `docker compose pull && up -d`. The container runs `prisma migrate deploy` before `server.js`, so **every schema change must ship with a committed migration**. The Prisma engine/client/schema `COPY` lines in the [Dockerfile](Dockerfile) are load-bearing — Next.js standalone output does not trace them.

The deploy workflow is currently **manual-dispatch only** while Epic 1 is in progress. It requires the `VPS_HOST`, `VPS_USER`, and `VPS_SSH_KEY` repository secrets.
